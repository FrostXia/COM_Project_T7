# 目录重构与整合说明

日期：2026-10-03。此次修改调整代码归属并接入控制算法，没有执行 git commit 或 push。

## 四个主要目录

```text
COM_Project_T7/
├─ Trajectory/             GUI、Simulink、运行调度及 experiments
├─ utils/                  路径、运动模型、参考、估计、噪声与指标
│  └─ +p7utils/            队友公共函数的 MATLAB 命名空间
├─ controller/             SF/LQR 增益、反馈核心、demo 与 mpc
├─ adapter/                平台位姿到误差转换及兼容接口
├─ tests/                  平台、算法和重构检查
├─ docs/                   中文说明与原交付资料
├─ setup_project7.m        统一加载明确目录
└─ start_project7.m        统一 GUI 启动
```

`+p7utils` 是 MATLAB package 目录，其调用形式为 `p7utils.defaults`，不是 `utils.defaults`。不直接将 `+p7utils` 加入 MATLAB 路径，只添加它的上级 utils。旧 `+p7core` 的调用已同步改名。

## 归属和调用

| 模块 | 文件/入口 | 说明 |
| --- | --- | --- |
| 界面与调度 | Trajectory/src/P7App、P7Session、p7_run | 运行周期、取消与日志；算法不读取会话真值 |
| 模型与几何 | utils/p7_motion、p7_make_path、p7_smooth_drawn、p7_check_path | 原平台精确积分、路径平滑与采样曲率检查 |
| 独立实验公共核心 | utils/+p7utils | 误差变换、离散化、误差 KF、噪声实验和指标 |
| 控制器 | controller/project7_q4_gains、project7_feedback_step | 固定名义 SF/LQR；前馈仍使用逐点参考角速度 |
| MPC | controller/mpc | LTV 或完整非线性误差预测；fmincon、输入修正量优化与热启动 |
| 平台适配 | adapter/p7_controller_adapter、project7_mpc_step | 全局估计位姿转本体误差，转换平台 config/ref |
| 独立实验 | Trajectory/experiments | run_sf_lqr_noise、run_mpc_noise、run_noise_sweep、launch_Project7_MPC |

GUI 新增 sf/lqr/mpc 选择与 MPC prediction 选择。GUI 和 external MPC 适配器默认 nonlinear；独立实验 p7utils.defaults 保留队友的 ltv 默认，运行前应显式记录。

connect_TrajectoryLab 兼容入口现在接受仓库根目录或 Trajectory 目录。它不再复制覆盖适配器，也不再自动切成 ideal 真值或关闭噪声；它只选择 time reference 与 nonlinear MPC，并保留界面原来的估计、噪声设置。

SF/LQR 使用交付函数中的名义参数作为候选：v0=0.5、wrNom=pi/4、poles=[-1,-2,-4]、Q=I3、R=1。函数支持 config.design 覆盖；GUI 没有增加权重或名义参数编辑栏。修改界面实际速度不会自动改变名义设计速度，固定增益的非名义性能必须单独验证。

## 已消除的重复

- 三个交付包不再并存，只提取一份公共模块和一份 MPC 核心。
- 四个 vendor 路径函数与原平台版本完全一致，保留 utils 中的一份。
- project7_q4_gains 只保留 controller 中的一份。
- GUI SF/LQR 与独立噪声实验调用同一个 project7_feedback_step 控制律。
- wrap 的计算集中于 utils/p7_wrap；原 MPC wrap 是薄兼容层，保留旧正 pi 边界约定。
- 所有运行入口使用 setup_project7；不用递归加载整个仓库，避免同名函数副本覆盖。

## 保留的相近逻辑及原因

| 项目 | 保留理由 |
| --- | --- |
| p7_defaults 与 p7utils.defaults | 两个明确的配置 profile：平台位姿 EKF 与队友误差测量实验；不能偷偷混成一个默认实验 |
| p7_motion 与 p7utils.pose_step | 前者精确零阶保持积分并返回 Jacobian；后者复现 Q5 先更新角度的 100 小步近似 |
| p7_estimator 与 p7utils.kf_error | 位姿 EKF 与误差状态 KF 的状态/测量定义不同 |
| p7_reference 与 p7utils.reference_data | 在线参考窗口与预计算时间参考职责不同，共用路径几何查询函数 |
| P7Session、simulate_q5、launch_Project7_MPC | 平台会话、完整独立噪声实验与原模板独立入口；尚未把运行循环全部合并 |
| p7_metrics 与 p7utils.noise_metrics | 日志格式、样本对齐和饱和统计定义不同；结果不能不加说明地直接混比 |

这些是已识别的下一阶段统一点。此次目录重构没有以相近名称为由删除不同数学方法，也没有宣称已完成统一噪声 Simulink 环境。

## 噪声与估计边界

平台 GUI 保留：位姿测量噪声、位姿 EKF，以及可选逐步 state noise；尚未将独立实验的角速度噪声与误差 KF 接入 Simulink GUI。

独立实验保留：直接给 xe/ye/thetae 测量添加独立高斯噪声、对实际角速度添加执行偏差。它先限幅指令，再加入执行噪声，物理角速度不再限幅。KF 默认 none，Qn/Rn 留空，启用时会要求配置。

初始协方差、噪声幅值、转向边界和输入文件格式没有因文件迁移而自动升级为最终验证参数。独立读取器仍接受 XY 两列或 [t,xr,yr,theta_r,omega_r] 五列；六列文件接口尚未实现。

## 验证

重构测试 test_project7_structure 检查 which 对应的文件位置、适配器符号与逐点前馈、两种参考入口的几何一致性。原平台失败测试改用 p7_unconnected_controller 显式测试拒绝行为；真实 external 入口已接 MPC。

run_all_tests(false,false) 运行重构、平台 MATLAB 和队友算法测试。run_all_tests(true,true) 加入 Simulink 和 GUI。本次实际检查结果在 重构验证记录.md 中，不把静态分析写成运行成功。

原平台源码已在工作会话目录另存 ZIP 备份，不放入项目 Git 路径。原交付 MD 归档在 docs/coop_original，供追溯，不作为新的执行指令或更高优先级要求。
