# 三步界面使用说明

更新：2026-10-04。入口：从仓库根目录运行 start_app。

## Step 1: Trajectory Setup（轨迹设置）

Load Preset Trajectory 选择 Line、Circle、Spiral；Draw A Trajectory 使用手绘编辑器。预设形状参数不在界面显示，由 utils/default_config.m 的 c.preset 命名字段设置，具体数值见本文末尾。

编辑器显示只读 Path Length (m)，它是最终处理曲线的长度。Smoothing Samples 为平滑初始尺度；Sampling Interval (m) 为沿路径取点的空间间隔。Desired Trajectory Speed (m/s) 可由用户修改；机器人与移动参考使用同一个速度。

Max Smoothing Shift 输入隐藏，代码仍采用 maxPathDeviation=0.20 m，限制手绘形状变化。控制器角速度限制不影响手绘输入，也不作为路径可行性确认条件。无效数据、过短路径、无法在形状偏移预算内完成平滑等基本处理错误仍显示。

Import Existing Trajectory 继续读取两列数值 XY CSV。Smooth & Preview 后直接 Confirm And Continue，不再需要 Validate path。Original 仅在手绘编辑器预览显示；主界面与运行结果只显示 Desired Trajectory。

## Step 2: Model Selection（模型选择）

- Control Model：Open Loop、State Feedback、LQR、MPC。
- Nominal Omega R (deg/s)：默认按 1 deg/s 过滤及转向样本规则自动计算。选择 State Feedback/LQR 时可手动修改，内部转换为 rad/s 并写入 nominalOverride；修改后 Step 3 和实际增益使用该值。输入必须非零。重新预览处理路径后恢复自动值。逐点参考角速度不被替换。
- State Feedback Pole 1/2/3：用户可修改三个不同负实数极点，标签不显示单位；内部仍按连续时间极点计算。
- MPC Preview Steps：预测步数。GUI 固定 nonlinear，没有 LTV 选择。
- Sample Period (s)：仿真及控制采样周期。
- Desired Duration (s)：只读，自动计算为 Path Length / Desired Trajectory Speed。修改路线或速度后重新计算；仿真在该时刻结束，不再提供 Max Duration 或额外追赶时间。
- Max Omega (rad/s)：用户设置正数，执行器采用对称范围 [-Max Omega,+Max Omega]；同时传入 MPC 约束。默认仍为 1.2 rad/s。
- Initial X/Y/Heading、Random Initial Pose、Update Initial Pose：设置、抽样并预览初始位姿。

随机位置以起点为中心，X 和 Y 各自在其路径跨度的 ±10% 内独立均匀取样；某轴跨度为零时借用另一轴跨度。朝向在 [-pi,pi) 上均匀抽样，不限制相对起始切线的角度。独立出生随机流不消耗噪声随机流。

标签、按钮及图例采用首字母大写；说明句保持普通句式。Previous Step / Next Step 导航；Open Simulink Model 已删除。

## Step 3: Run Simulation（运行仿真）

Noise 打开 Noise Parameters 弹窗，三类噪声均有独立开关和标准差。Apply 应用到下一次运行，清空旧结果，但保留轨迹确认、初始位姿及当前 Step 3；Cancel 不保存弹窗修改。

默认配置：

| 通道 | 默认开关 | 标准差 |
|---|---|---|
| Measurement Noise | 开 | X/Y 各 0.03 m；当前仅测位置 |
| Control Noise | 开 | 0.1 rad/s |
| State Noise | 关 | X/Y 各 0.003 m，heading 0.005 rad，每次状态更新 |

当前 sensorMode='position'，Measurement Heading Std 显示但禁用；朝向由 EKF 估计。代码改为 pose 传感器时该项可用。State Noise 是真实位姿更新的随机扰动，Measurement Noise 是传感器输出扰动。

控制噪声由独立高斯随机流生成，处理顺序为：

1. 控制器输出限幅得到 omegaCommand。
2. 添加零均值高斯控制噪声，默认标准差 0.1 rad/s。
3. 再次限幅得到 omegaPhysical，真实机器人积分使用它。

估计器只读取已发送的指令，不读取未知的物理扰动。原始高斯噪声和限幅后的有效扰动分别记录；接近角速度边界时，有效扰动不再是严格的零均值高斯分布。

这是假设有最终执行器饱和的简化模型，不证明真实机器人的实测角速度永远不会超限；噪声标准差为仿真参数，未标定真实硬件。

滤波协方差没有 UI 输入：utils/default_config.m 中 estimatorQn / estimatorRn 为可选固定 3×3 矩阵；留空时按代码中的噪声统计量构造。控制噪声的过程协方差采用局部输入敏感度近似，接近饱和处不保证精确。LQR/MPC 的 Q/R 同样在代码中配置。

Run 启动 Simulink，Stop 请求停止，Export Last Result 导出。

## 图像、结果与导出

主图只显示 Desired Trajectory、Robot Initial Position、Initial Heading，以及红色虚线 Robot Trajectory 和当前 Robot Heading。Robot Trajectory 是真实运动，可受扰动影响；不使用“无噪声轨迹”名称。估计轨迹隐藏，但估计数据、估计误差保留。

Step 3 配置摘要以两列显示，名称左对齐、数值右对齐，轨迹、时间、出生位姿与三类噪声拆成独立行。底部 Results 框已删除；运行描述和完整错误保留在底部文本区。后台评价计算和结果导出保留。Control And Timing 展示实际执行角速度与控制器计算时间。

正常运行到 Desired Duration 即结束，无论机器人是否到达终点。Stop 仍可提前结束，错误仍会中断运行。MPC 的预测窗口超出参考终点时仍使用终点填充，但不会因此延长实际仿真。到达终点不自动代表高跟踪精度。

数据按 Sample Period 记录，不生成 Desired Duration 之后的样本。如果 Desired Duration 不是采样周期的整数倍，最后一条记录可能早于结束时刻，差值小于一个采样周期。CSV 中 Desired Duration 表示计划终止时刻，Recorded Sample Duration 表示首末记录间的时间跨度。

每次导出仅生成两个 CSV，保存在 results 下，共用 yyyyMMdd_HHmmss_SSS 时间戳，不合并实验。trajectory_时间戳.csv 是完整平滑后的 Desired Trajectory（无表头，仅 X、Y 两列），可由 Import Existing Trajectory 直接读取，即使实验提前停止也导出整条路线。evaluation_时间戳.csv 使用 Metric、Value、Unit 三列，保存实验配置及独立可计算的指标，全称展示 Root Mean Square Error。不再生成 run.mat、timeseries.csv、summary.txt 或 trajectory.png；已有导出文件不删除。

收敛时间、容限达标时间比例、终点到达判定和控制努力等待评价规则确认，暂不导出；额外完成时间已删除。误差指标标为 Full Run，仅使用实际记录的运行样本；Position/Heading Error 使用日志中的参考点，Path Distance 使用到整条 desired 路径线段的最近距离。饱和时间比例按实际角速度和各时间间隔加权，计算耗时按日志记录的控制调用统计。无运行样本时仍导出轨迹与配置，评价值为 NaN。


## 验证

run_all_tests(false,false) 执行算法及 MATLAB 循环测试；run_all_tests(true,true) 加入 Simulink 比对和隐藏界面功能检查。测试覆盖单次运行、原生界面和导出；不再包含独立或批量实验。

## 预设路线参数

utils/default_config.m 使用 c.preset.line.length=30 m、c.preset.circle.radius=10 m（固定完整一圈，无 turns 配置）、c.preset.spiral.initialRadius=8 m、growthRate=0.15 m/rad、turns=5。GUI 使用上述统一配置。utils/generate_trajectory.m 的数值向量入口仅保留给显式几何测试；测试参数不会自动改成 GUI 默认值。
