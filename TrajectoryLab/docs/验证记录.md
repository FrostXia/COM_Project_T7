## MATLAB 运行受阻

本次环境可找到 `D:/Program_Files/MATLAB/R2025a/bin/matlab.exe`。

首次批处理启动报告 `System Error: File system inconsistency`。取得 MathWorks 配置／缓存目录权限并指定独立偏好目录后，启动进入下一阶段，但报告：

```text
无法与所需的 MathWorks 服务通信(错误 5201)。
```

开启网络访问后再次启动，仍然报告相同错误。错误发生在 MATLAB 执行用户代码之前。因此：

- 没有运行 `run_tests`，不能报告运行测试通过。
- 没有用 MATLAB 生成或编译 `.slx`；已交付 `build_p7_model.m`，首次本地启动时自动生成。
- 没有核实 Simulink 和各工具箱的许可证可用性。
- 没有人工操作界面或验证鼠标绘制；这些属于本地验收项。

没有重置或删除用户已有 MATLAB 设置，没有修改系统服务或绕过许可证。

## 自动测试覆盖范围

`run_tests` 提供以下检查，但在当前环境中尚未执行：

1. 直行和完整圆周运动的不变量、状态雅可比。
2. 预设及手绘路径处理，拒绝过小圆半径。
3. 参考窗口维度、时间参考独立于实际位置、末端预览不冻结。
4. 航向测量跨越 ±pi 时的 EKF 创新、纯推算忽略测量。
5. 同种子重复试验一致，真实状态与估计状态分开。
6. 正式算法接口不泄露真实初值，未接入和非有限输出明确失败。
7. 取消运行与正常完成区别保存。
8. MATLAB 核心验证循环与 Simulink 的逐点状态一致性。
9. Simulink 中的受控求解失败及停止行为。
10. 隐藏创建界面、路径确认、不可行路径的运行前拦截。

## 建议本机验收顺序

正常打开 MATLAB，进入 TrajectoryLab 目录：

```matlab
run_tests(false,false)
build_p7_model
run_tests(true,true)
start_trajectory_lab
```

然后手动确认：直线路径运行、过小圆半径被拒绝、手绘平滑预览、运行中 Stop、结果导出、external 未接入时失败提示。再逐步加入队友正式控制器。

`run_tests` 会保存真正执行时的输出到 `results/test_output.txt`。只有本机出现通过结果后，才应将对应项目从“未执行”更新为“通过”。
